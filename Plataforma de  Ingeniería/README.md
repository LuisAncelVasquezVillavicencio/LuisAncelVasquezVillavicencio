# Plataforma de Ingeniería - Estructura del Proyecto

Este repositorio contiene la documentación, planificación, arquitectura y recursos para el desarrollo de la Plataforma de Ingeniería.

## Estructura de Carpetas

- [actividades/](./actividades/)
  - Planificación, cronogramas, estimaciones de tiempo, roles y tareas del proyecto.
- [arquitectura/](./arquitectura/)
  - Diagramas, modelos y documentación de la arquitectura general del sistema.
- [mokup/](./mokup/)
  - Prompts, recursos y archivos relacionados con el diseño de mockups y prototipos de la plataforma.

## Descripción de Carpetas Excluidas

- La carpeta `doc/` contiene los documentos fuente, requerimientos y archivos de referencia del proyecto.
- La subcarpeta `arquitectura/material/` contiene materiales gráficos y diagramas exportados.
